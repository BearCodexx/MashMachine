## Возможности

| Функция | Описание |
|---|---|
| **Разделение аудио** | Demucs v4 делит трек на чистый вокал и полный инструментал (ударные, бас и синты) |
| **Клонирование голоса** | RVC через сервис Applio преобразует оригинальный вокал в выбранный тембр |
| **Сведение трека** | Склейка нового вокала с оригинальным минусом через FFmpeg без потери громкости |
| **Регулировка баланса** | Настройка относительной громкости вокала от 50% до 200% |
| **Персональные настройки** | Индивидуальный выбор модели голоса для каждого пользователя бота |
| **Очередь обработки** | Асинхронный воркер задач с уведомлением пользователя о позиции в очереди |
| **Лимиты и статистика** | Дневные лимиты генераций для пользователей и безлимит для администраторов |
| **Админ-панель** | CLI-интерфейс для просмотра статистики, чатов, блокировки и рассылок |

## Структура проекта

```text

├── applio/               # Встроенный каталог Applio (инференс RVC на порту 6969)

├── run_mashuper.bat      # Скрипт быстрого запуска бота с контролем Applio
```

## Установка и запуск

### 1. Подготовка окружения

Клонируйте проект и перейдите в его каталог:

```bash
git clone https://github.com/BearCodexx/MashMachine.git
cd MashMachine
```

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

### 2. Установка зависимостей

Установите основные зависимости:

```bash
pip install -r requirements.txt
```

> [!IMPORTANT]
> Для быстрой обработки треков через Demucs и RVC требуется видеокарта NVIDIA.
> Убедитесь, что PyTorch установлен с поддержкой CUDA:
> ```bash
> pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
> ```

### 3. Настройка и запуск бота

Запустите проект единым скриптом:

```bash
python run.py
# или в Windows:
run_mashuper.bat
```

> [!NOTE]
> **Мастер первоначальной настройки**:
> Если движок Applio еще не настроен, консоль автоматически предложит:
> - Скачать официальную сборку **Applio v3.6.5** с Hugging Face (~3.5 ГБ) с визуальным индикатором загрузки и авто-распаковкой;
> - Либо указать путь к уже скачанной папке с Applio на диске (путь сохранится в `.env`);
> - Автоматически загрузить стартовый пак моделей голосов (**Глад Валакас**, **Дора**) из GitHub Releases.

Скрипт сам проверит видеокарту (CUDA/RTX), поднимет сервис Applio на порту `6969` (если он еще не запущен) и запустит Telegram-бота со студийным логгированием.

### 4. Запуск консоли администратора

Запуск CLI-панели управления:
```bash
python admin_cli.py
# или в Windows:
run_admin.bat
```

## Добавление новых моделей голосов

1. Поместите веса модели в каталог `applio/logs/<имя_модели>/`:
   ```text
   applio/logs/
   └── my_voice/
       ├── my_voice.pth
       └── my_voice.index
   ```
   > Название папки и файлов `.pth` и `.index` должны строго совпадать.

2. Зарегистрируйте голос в словаре `AVAILABLE_VOICES` в файле `bot.py`:
   ```python
   AVAILABLE_VOICES = {
       "valakas": { ... },
       "dora": { ... },
       "my_voice": {
           "name": "Мой голос",
           "lang": "Русский",
           "gender": "Мужской",
           "pitch_map": {
               "Грубый мужской": -18,
               "Мужской": -20,
               "Грубый женский": -21,
               "Женский": -24
           }
       }
   }
   ```
   После этого модель автоматически появится в библиотеке голосов и станет доступна по команде `/my_voice`.

## Команды админ-панели (admin_cli.py)

| Команда | Описание |
|---|---|
| `users` | Список всех пользователей, их ID и активность |
| `stats` | Общая сводка (пользователи, блокировки, количество обработок) |
| `blocked` | Список заблокированных пользователей |
| `block <id>` | Заблокировать пользователя по Telegram ID |
| `unblock <id>` | Разблокировать пользователя |
| `chat <id>` | Просмотр последних сообщений диалога с пользователем |
| `msg <id> <текст>` | Отправить прямое сообщение пользователю от имени бота |
| `broadcast <текст>`| Массовая рассылка сообщения всем активным пользователям |
| `file <id>` | Скопировать последний готовый файл пользователя в текущую папку |
| `help` | Справка по доступным командам |
| `exit` | Выход из панели администратора |
